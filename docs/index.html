きなこPDF

無料・完全ローカル PDFエディタ

安心・安全。クラウドへのアップロードなし。
PDFの処理はすべて自分のパソコンの中で行います。

無料ダウンロード（KinakoPDF.exe）

ダブルクリックで起動できる exe 版を配布予定です。ソースコード版も同じ場所に置きます。
exe 版は GitHub Actions で自動ビルドします。初回は手動で試して起動確認してから公開します。

できること

  • 墨消し（物理削除） — 消した文字が保存後のPDFに残っていないか自動で検証します
  • テキスト編集 — 既存の文字・数字の書き換え、新しい文字の追加
  • ペン・マーカー・トリミング・回転 — ページの並べ替え・挿入・削除も
  • 見開き全画面リーダー — F5で本のように見開きで読めます
  • スキャン明細の色抜き・OCR（Windows専用） — 範囲OCR（Ctrl+Alt+O）つき
  • 表の電卓 — Ctrl+クリックでPDF内の数字を選ぶと合計します
  • フォルダ一括読込 — 複数PDFをまとめて1つの本として読み込み（結合機能）
  • 文字検索・印刷・最近開いたファイル

使い方（3ステップ）

  1. 上のボタンからzipをダウンロードして解凍する
  2. pip install -r requirements.txt を実行する
  3. python secure_local_pdf_editor.py で起動する

必要なもの：Python 3.11以上、PyQt6、PyMuPDF（requirements.txtに記載）。新しいライブラリは追加していません。

注意書き

  • OCR（スキャン色抜き・範囲OCR）はWindows専用です。色抜き以外の編集機能はどのOSでも使えます。
  • 墨消しの検証は文字層が中心で、画像や図形の残りまでは完全には確認していません。
  • パスワード付きPDFを上書き保存すると、暗号化が解除される場合があります。保存時の確認ダイアログをよく読んでから選んでください。
  • WindowsでのOCRの生の動作は未検証です。お試しのうえ、気づいた点があれば教えてください。
