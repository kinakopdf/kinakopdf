なぜ作ったのか

個人情報の流出のニュースは、あとを絶ちません。便利なAIに書類をアップロードすれば、面倒な作業は一瞬で片付きます。しかし、その書類の中には、名前や住所、カード番号など、大切な個人情報が入っています。

きなこPDFは、そんな不安から生まれました。AIにアップロードする前に、自分のパソコンの中で個人情報を消しておくためのソフトです。墨消しで名前や住所を物理的に消してからアップロードすれば、大切な情報を外に出さずにすみます。

作ったのは大きな会社ではなく、個人です。目指したのは「自分の大切な書類を、自分で守れる道具」。機能の派手さよりも、安心して使えることをいちばんに考えて作っています。

安心して使える理由

  • 完全ローカル — PDFの処理はすべて自分のパソコンの中で完結する設計です。
  • オープンソース — ソースコードをすべて公開しています。中身がどうなっているか、誰でも確認できます。
  • 使う部品は2つだけ — 使う部品（ライブラリ）は、画面を作る PyQt6 と、PDFを扱う PyMuPDF の2つだけに絞っています。部品が少なければ、余計なものが混ざる心配も少なくなります。

個人制作のソフトのため、Windowsのセキュリティ警告（「WindowsによってPCが保護されました」など）が出ることがあります。これは、まだ広く知られていない個人のソフトに出やすい表示で、ウイルス感染の警告とは別ものです。出たときの起動のしかたは、下の「はじめての きなこPDF」に手順を書いてあります。不安な方は、上の「オープンソース」のソースコードをご確認ください。

できること

  • 墨消し墨消し（物理削除） — 上から塗りつぶす方式とは違い、選んだ文字や画像のデータを完全に削除し、復旧できないようにします。保存したあとのPDFをほかのソフトで開いても、消した内容は復活しません。消したあと、文字が本当に残っていないかを自動で検証する機能つきです
  • 編集テキスト編集 — 既存の文字・数字の書き換え、新しい文字の追加
  • 編集ペン・マーカー・トリミング・回転・折りたたみ表示 — ページの並べ替え・挿入・削除も。折りたたみ表示は、ページの一部の帯を隠して詰めて表示する機能です（表示だけ・PDFは変わりません）
  • 読む見開き全画面リーダー — F5で本のように見開きで読めます（表紙の有無も選べます）。通常画面で全ページを縦にスクロールして読む表示もあります
  • OCRスキャン明細の色抜き・OCR（Windows専用） — 範囲OCR（Ctrl+Alt+O）つき。OCRはWindowsに標準で入っている機能だけを使い、処理はパソコンの中で完結します。その代わり、読み取りの精度には限界があります。手書き文字や、かすれた文字・小さな文字はうまく読めないことがあります。結果は必ず目で確認してください。
  • 計算表の電卓 — Ctrl+クリックでPDF内の数字を選ぶと合計します
  • 便利フォルダ一括読込 — 複数PDFをまとめて1つの本として読み込み（結合機能）
  • 便利Excel出力 — PDFの表をExcel（.xlsx）に書き出せます
  • 便利テキスト選択→コピー — 文字をドラッグで選ぶと「📋 コピー」ボタンが出て、押すとコピーして自動で閉じます。テキスト編集ダイアログにもコピーボタンがあります
  • 便利文字検索・印刷・最近開いたファイル

こんな方におすすめです

オンラインの編集サイトは便利ですが、書類をサーバーに送ることに不安を感じる方も多いと思います。きなこPDFは、PDFを外部に送らず、自分のパソコンの中だけで編集できるように作りました。

墨消しで個人情報を確実に消したい方、スキャンした書類をOCRで文字にしたい方、面倒な登録やインストールなしにすぐ使いたい方におすすめです。Windowsのパソコンでお使いいただけます。

使い方（3ステップ）

  1. 上のボタンから KinakoPDF.exe をダウンロードする
  2. ダウンロードした exe をダブルクリックする
  3. PDFを開いて、墨消しや編集をする

ソースコード版を使う場合：Python 3.11以上、PyQt6、PyMuPDF（requirements.txtに記載）が必要です。python secure_local_pdf_editor.pyw で起動します。新しいライブラリは追加していません。

※ 安定版 v1.0.6 を公開中です（2026-11-22）。

はじめての きなこPDF

きなこPDFって、なに？

無料で使えるPDFの編集ソフトです。いちばんの特徴は「ぜんぶ自分のパソコンの中でやる」こと。インターネットにファイルを送らないので、名前や住所、カード番号の入った書類でも安心して使えます。

インストールはいりません。ダウンロードしてダブルクリックするだけ。Windowsのパソコンで使えます。

はじめの5分

  1. ホームページの「無料ダウンロード（KinakoPDF.exe）」からダウンロードする
  2. ダウンロードした exe をダブルクリックする
  3. PDFを開く（ドラッグ＆ドロップでも開けます）
  4. まずはコピーを作って試すのがおすすめです。大事な原本はそのまま残しておけます

青い画面「WindowsによってPCが保護されました」が出たら

初めて起動するとき、Windows 11では青い警告画面が出ることがあります。これは、発行元がまだ知られていないアプリへの確認で、個人で作ったソフトにはよく出るものです（ウイルスということではありません）。次の手順で起動できます。

  1. 画面の「詳細情報」という文字を押す
  2. 「実行」ボタンが出てくるので、それを押す

※ 青い画面が出ずに、ダブルクリックしても何も起きない場合は、「スマートアプリコントロール」という別の仕組みが止めていることがあります。そのときは、Windowsセキュリティ →「アプリとブラウザー コントロール」→「スマートアプリコントロールの設定」から一時的にオフにすると起動できます。セキュリティを下げる操作なので、起動できたらオンに戻してください。不安な方は、ソースコードを公開しているので中身を確認できます。

まず覚えたい3つのこと

1. 墨消し — 消したい文字を、データごと消す

名前や住所など、見せたくない部分を選びます。上から塗りつぶすのではなく、文字のデータそのものを消すので、保存したあと他のソフトで開いても復活しません。AIに書類を渡す前に、ここで個人情報を消しておくのが、きなこPDFのいちばんの使い方です。

2. 文字の書き換え — 数字や文字を直す

PDFの中の文字をそのまま書き換えたり、新しい文字を足したりできます。ドラッグで文字を選ぶと「📋 コピー」ボタンが出て、押すとコピーして画面が閉じます。

3. 見開きで読む — 本みたいに読む

F5キーで見開きの全画面リーダーになります。左クリックで次へ、右クリックで前へ進みます。表紙あり・なしも選べます。ふつうに縦にスクロールして読む表示もあります。

あると便利なもの

  • フォルダ一括読込 — 複数のPDFをまとめて1冊の本として読む
  • Excel出力 — PDFの表をExcel（.xlsx）に書き出す
  • 表の電卓 — Ctrl+クリックでPDF内の数字を選ぶと合計する
  • OCR（Windows専用） — スキャンした書類の文字を読み取る。範囲OCRは Ctrl+Alt+O
  • 文字検索・印刷・最近開いたファイル

気をつけること

  • 墨消しは元に戻せません。消す前は、かならずコピーを取っておいてください。
  • 墨消ししたあと、文字が本当に残っていないか自動で確かめる機能があります。でも大切な部分は、保存後に自分の目でも確かめてください。
  • OCRはWindowsに標準で入っている機能だけを使っています。手書きや、かすれた文字・小さな文字はうまく読めないことがあります。結果はかならず目で確認してください。
  • パスワード付きPDFを上書き保存すると、暗号化が解除される場合があります。保存時の確認ダイアログをよく読んでから選んでください。

注意書き

  • OCR（スキャン色抜き・範囲OCR）はWindows専用です。色抜き以外の編集機能はどのOSでも使えます。
  • 墨消し自体は、文字や画像のデータを完全に削除し、復旧できないようにします。自動の検証は文字層が中心で、画像や図形の残りまでは完全には確認していません。とくに大切な部分は、保存後にご自身でも目でご確認ください。
  • パスワード付きPDFを上書き保存すると、暗号化が解除される場合があります。保存時の確認ダイアログをよく読んでから選んでください。
