なぜ作ったのか

今は、個人情報の流出のニュースがあとを絶ちません。便利なAIに書類をアップロードすれば、面倒な作業は一瞬で片付きます。しかし、その書類の中には名前や住所、金額など、大切な個人情報が入っています。

きなこPDFは、そんな不安から生まれました。AIにアップロードする前に、自分のパソコンの中で個人情報を消しておくためのソフトです。墨消しで名前や住所を物理的に消してからアップロードすれば、大切な情報を外に出さずにすみます。

作ったのは、プロの会社ではなく個人です。だからこそ「自分の大切な書類を、自分で守れる道具」を目指しました。派手な機能はありませんが、安心して使えることをいちばんに考えています。

安心して使える理由

  • 完全ローカル — PDFの処理はすべて自分のパソコンの中で行います。クラウドへのアップロードは一切ありません。
  • オープンソース — ソースコードをすべて公開しています。中身がどうなっているか、誰でも確認できます。
  • 使う部品は2つだけ — 画面を作る PyQt6 と、PDFを扱う PyMuPDF。この2つだけを、極限まで絞って使っています。部品が少なければ、余計なものが混ざる心配も少なくなります。

個人制作のソフトのため、Windowsのセキュリティ警告（「WindowsによってPCが保護されました」など）が出ることがあります。これは、まだ広く知られていない個人のソフトに出やすいもので、ウイルスということではありません。不安な方は、上の「オープンソース」のソースコードをご確認ください。

できること

  • 墨消し墨消し（物理削除） — 文字を上から塗りつぶすのではありません。選んだ文字や画像のデータを完全に削除し、復旧できないようにします。だから、保存したあとのPDFをほかのソフトで開いても、消した内容は復活しません。消したあと、文字が本当に残っていないかを自動で検証する機能つきです
  • 編集テキスト編集 — 既存の文字・数字の書き換え、新しい文字の追加
  • 編集ペン・マーカー・トリミング・回転 — ページの並べ替え・挿入・削除も
  • 読む見開き全画面リーダー — F5で本のように見開きで読めます
  • OCRスキャン明細の色抜き・OCR（Windows専用） — 範囲OCR（Ctrl+Alt+O）つき。OCRはWindowsに標準で入っている機能だけを使い、文字を外部のサービスに送ることはありません。その代わり、読み取りの精度には限界があります。手書き文字や、かすれた文字・小さな文字はうまく読めないことがあります。結果は必ず目で確認してください。
  • 計算表の電卓 — Ctrl+クリックでPDF内の数字を選ぶと合計します
  • 便利フォルダ一括読込 — 複数PDFをまとめて1つの本として読み込み（結合機能）
  • 便利文字検索・印刷・最近開いたファイル

使い方（3ステップ）

  1. 上のボタンから KinakoPDF.exe をダウンロードする
  2. ダウンロードした exe をダブルクリックする
  3. PDFを開いて、墨消しや編集をする

ソースコード版を使う場合：Python 3.11以上、PyQt6、PyMuPDF（requirements.txtに記載）が必要です。python secure_local_pdf_editor.pyw で起動します。新しいライブラリは追加していません。

注意書き

  • OCR（スキャン色抜き・範囲OCR）はWindows専用です。色抜き以外の編集機能はどのOSでも使えます。
  • 墨消し自体は、文字や画像のデータを完全に削除し、復旧できないようにします。自動の検証は文字層が中心で、画像や図形の残りまでは完全には確認していません。とくに大切な部分は、保存後にご自身でも目でご確認ください。
  • パスワード付きPDFを上書き保存すると、暗号化が解除される場合があります。保存時の確認ダイアログをよく読んでから選んでください。
