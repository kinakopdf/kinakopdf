Chromebookで使う

きなこPDFはWindows用のexeのほかに、ソースコード版があります。
Chromebookでは、Chromebookの中のLinuxからソースコード版を起動します。

← きなこPDFのトップへ戻る

まず知っておくこと

  • Windows用の KinakoPDF.exe は、Chromebookではそのまま動きません。
  • Chromebookの中のLinux（開発環境）を使います。設定でオンにするだけの、Chromebookの標準機能です。
  • OCR（スキャン色抜き・範囲OCR）はWindows専用なので、Chromebookでは使えません。ほかの編集機能は使えます。
  • ChromebookのLinuxは、パソコンより少し遅いことがあります。

手順

  1. Linuxをオンにする
    「設定」→「デベロッパー」→「Linux開発環境」をオンにします。初めてのときは、少し時間がかかります。
  2. ターミナルを開く
    アプリ一覧から「ターミナル」を開きます。
  3. ソースコードをダウンロードする
    GitHubのページから「Code」→「Download ZIP」でzipをダウンロードし、Linuxのフォルダに解凍します。または、ターミナルで次のように入力します。 
    git clone https://github.com/kinakopdf/kinakopdf.git
cd kinakopdf
  4. 必要なものを入れる
    ターミナルで次のように入力します。 
    sudo apt update
sudo apt install -y python3-pip libegl1 libgl1 libdbus-1-3 libxkbcommon0 libfontconfig1 libglib2.0-0 fonts-noto-cjk
pip install -r requirements.txt --break-system-packages
  5. 起動する
    ターミナルで次のように入力します。 
    python3 secure_local_pdf_editor.pyw

    .pyw は中身はただのPythonファイルです。Windowsだとダブルクリックで黒い画面が出ないように .pyw にしてあるだけで、Linuxでは python3 でそのまま動きます。

うまくいかないとき

  • 起動時にライブラリ不足のエラーが出る場合は、手順4のコマンドをもう一度実行してください。
  • 文字化けする場合は、日本語フォント（fonts-noto-cjk）が入っているか確認してください。
  • それでも直らない場合は、ご感想フォームからお知らせください。エラーの文章をコピーして貼ってもらえると助かります。
