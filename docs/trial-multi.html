入っている機能

安定版の機能（墨消し・トリミング・文字編集・折りたたみ表示・Excel出力など）に加えて、次の機能が入っています。

  • パスワード保護・解除 — PDFにパスワードをかける・はずす（AES-256）
  • PDF圧縮 — ファイルサイズを小さくする
  • PDF分割 — ページ範囲を指定して分ける（例：1-3,5）
  • フォーム入力 — PDFの入力欄に文字を入れて確定（フラット化）
  • 電子印鑑・スタンプ — 日付入りの丸い印鑑と、四角いスタンプ8種類
  • しおりの表示・編集 — しおり（ブックマーク）を見る・直す
  • ヘッダー・フッター・透かし — ページ番号や透かし文字を入れる
  • 証憑OCR→一覧Excel/CSV（半自動） — 領収書や請求書の日付・取引先・金額の候補を出して、確認してから一覧にします（会計向け）
  • 電帳法リネーム — ファイル名を「日付_取引先_金額.pdf」に自動でつけ直す（確認してから変更）
  • インボイス番号チェック — 登録番号（T＋13桁）が正しいか確認
  • 複数PDF横断検索 — フォルダ内のPDFをまとめて文字検索
  • 2つのPDFのテキスト比較 — 2つのPDFの文字の違いを見る
  • 個人情報パターンの墨消し候補 — メールアドレス・電話番号・マイナンバー・口座番号の候補を出して、選んだものだけ墨消し
  • 署名の挿入 — 画像の署名や、手書きパッドで書いた署名を入れる
  • 写真をPDF化 — 写真を選ぶと、書類を自動で切り抜き・傾き補正してPDFにします（四隅を手で直すこともできます）
  • 2ページを1枚に結合 — FAXで途中で切れて2ページになった書類を、見開き風のプレビューで継ぎ目を調整して1枚に戻せます。全画面表示と高画質プレビュー、上下・左右の位置の微調整、元のページを残す選択にも対応しました（文字データは保てます）
  • 台形補正 — 台形に歪んだ書類を、4つの角を合わせてまっすぐな長方形に直します（補正したページは画像になります）
  • 傾き補正 — 傾いたページの角度を自動で測って、まっすぐに直します（角度の確認と微調整ができます）
  • レシート分割 — 複合機の原稿台いっぱいにレシートを並べて取り込んだPDFを、レシートごとのPDFファイルに自動で切り分けます（保存の前に、検出した位置をプレビューで確認でき、枠の追加・削除・移動・大きさの変更もできます）
  • 文字データの表示と修正 — PDFの文字データを元の配置で表示し、バラバラの文をくっつけてPDFに反映できます。スキャンPDFは見た目そのままに、内部の文字データだけ差し替えもできます
  • 画像だけのPDFとして保存 — 見た目はそのまま残して、文字データだけを消したPDFを別ファイルに保存できます
  • 見開きリーダーの強化 — 続きから開く、右開き・左開き、全画面表示など
  • ボタンの整理と並び替え — ボタンをメニューにまとめたり、自分で並びを変えたりできます

目玉機能ピックアップ

他のPDFソフトではあまり見かけない、きなこPDFならではの機能を集めました。使い方は、次の「取説」にまとめています。

  • 📝 文字データの修正 — PDFの中の文字データを、元の配置のまま表示して直せます。スキャンした書類では、見た目の画像はそのままに、内部の文字データだけを差し替えることもできます
  • 🖼️ 画像だけのPDFとして保存 — 見た目はそのまま残して、文字データだけを取り除いたPDFを作れます
  • 🧩 FAXで切れた2ページを1枚に — 途中で切れて2ページになった書類を、継ぎ目を調整して1枚に戻せます
  • 📐 傾き補正 — 傾いたページの角度を自動で測って、まっすぐに直します
  • 🔶 台形補正 — 台形に歪んだ書類を、4つの角を合わせて長方形に直します
  • 📕 見開きリーダー — 本のように見開きで読める表示です。続きから開く機能や、右開き・左開きの切り替えに対応しています

取説（目玉機能の使い方）

どの機能も「PDFを開く → 対象のページを選ぶ → 実行する」の流れで使えます。実行した操作は「元に戻す」で取り消せます。元のファイルは、保存するまで変わりません。

📝 文字データを直す

  1. PDFを開いて、編集の段にある「📝 文字データ」ボタンを押します
  2. 直したい文字をクリックして選びます。バラバラに分かれた文は、ドラッグで範囲を選んで「くっつける」を押すと一文になります
  3. 内容を書き直して「PDFに反映」を押します
  4. スキャンした書類の場合、見た目の画像は変わらず、内部の文字データだけが直した内容に差し替わります。AIに読ませるときや、コピー・検索の結果がこちらに変わります

🖼️ 画像だけのPDFとして保存する

  1. 「📝 文字データ」の画面を開きます
  2. 「🖼️ 画像だけのPDFとして保存」を押して、保存先とファイル名を選びます
  3. 見た目は元のまま、文字データだけを取り除いたPDFが、別のファイルとして保存されます

🧩 FAXで切れた2ページを1枚に戻す

  1. 左のページ一覧で、くっつけたい2ページを選びます（選んでいないときは、開いているページと次のページが対象になります）
  2. ページ管理の「🧩 2ページを1枚に結合」を押します
  3. 見開き風のプレビューで、並べ方（左右／上下）を選び、真ん中の切り取り量をスライダーで調整します。2枚目の位置がずれているときは、「位置の微調整」で上下・左右にずらせます。大きく見たいときは「⛶ 全画面（F11）」を押してください
  4. 元の2ページも残したいときは、「元のページを残す」にチェックを入れます
  5. 「結合する」を押すと、2ページが1枚になります。文字データはそのまま残ります

📐 傾き補正（まっすぐにする）

  1. ページ一覧で、直したいページを選びます（複数選ぶと、まとめて直せます）
  2. ページ管理の「📐 傾き補正」を押します
  3. 自動で測った角度がページごとに表示されます。スライダーと数値で微調整もできます
  4. 「まっすぐにする」を押すと、ページがまっすぐになります。文字データはそのまま残ります

🔶 台形補正

  1. ページ一覧で、直したいページを選びます
  2. ページ管理の「🔶 台形補正」を押します
  3. 書類の4つの角を、ドラッグで実際の隅に合わせます（最初は自動検出の結果が出ます）
  4. 「補正する」を押すと、長方形に直ったページに置き替わります。補正したページは画像になります

📕 見開きリーダー

  1. PDFを開いて、見開き表示のボタンを押します（F5キーでも開けます）
  2. 画面のどこでも、左クリックで次のページ、右クリックで前のページへ進みます
  3. 右開き・左開きの切り替え、全画面表示、ページのスライダーも画面の中で操作できます
  4. 閉じるときは Esc キーか F5 キーです。次に開くと、前回の続きから開きます

そのほかの機能（パスワード・圧縮・分割・フォーム入力・印鑑・しおり・会計向けの機能など）は、画面上のボタンや「📒 会計試作」の段から選べます。
