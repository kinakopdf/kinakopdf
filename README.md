# Secure Local PDF Editor（安全・完全ローカル PDF エディタ）

**公式ホームページ（ダウンロードはこちら）: https://kinakopdf.github.io/kinakopdf/**

PDF を開いて編集・保存する、完全ローカルのデスクトップアプリです。
ネットワークには一切接続しません。PDF の処理はすべて自分のパソコンの中で行います。

## 売り

- **安心・安全・完全ローカル**: クラウドへのアップロードなし。墨消しは文字データを物理的に削除し、残存がないか検証してから保存します。
- **墨消し（物理削除）**: 範囲墨消し・テキスト消去。消した文字が保存後の PDF に残っていないか自動で検証します。
- **テキスト編集**: 既存の文字・数字を書き換えたり、新しい文字を追加したりできます。
- **ペン・マーカー・トリミング・回転**: ペン描画、マーカー、ページの回転・トリミング・並べ替え・挿入・削除。
- **見開き全画面リーダー**: F5 で本のように見開きで読めます。
- **スキャン明細の色抜き・OCR（Windows 専用）**: スキャンした明細の黄・赤・青の背景や点々を消し、Windows 標準 OCR で文字認識します。範囲 OCR（Ctrl+Alt+O）もあります。
- **表の電卓**: Ctrl+クリックで PDF 内の数字を選ぶと合計します。
- **フォルダ一括読込**: フォルダ内の複数 PDF をまとめて 1 つの本として読み込みます。
- **文字検索・印刷・最近開いたファイル**

## 必要なもの

- Python 3.11 以上
- PyQt6
- PyMuPDF

## 使い方

```bash
pip install -r requirements.txt
python secure_local_pdf_editor.pyw
```

PDF をダブルクリックで開くこともできます（Windows では「既定の PDF に設定」から登録できます）。

起動時に古い OCR 一時フォルダと `__pycache__` を自動で掃除します。

## テスト

```bash
QT_QPA_PLATFORM=offscreen python -m unittest tests.test_core_logic -v
```

## 注意

- OCR（スキャン色抜き・範囲 OCR）は Windows 専用です。Windows 以外ではダイアログを開く前にその旨を表示します。色抜き以外の編集機能はどの OS でも使えます。
- パスワード付き PDF を上書き保存すると、暗号化が解除される場合があります。保存時に確認ダイアログが出るので、よく読んでから選んでください。
- 保存はアトミックに行い、保存後にページ数を検証します。編集中のデータは、保存に失敗しても保護されます。
